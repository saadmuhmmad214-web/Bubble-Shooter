## 🎯 About The Game

**Bubble Shooter** is a classic, arcade-style puzzle match-3 browser game reimagined using modern web technology. Aim, shoot, and pop colorful bubble clusters on an authentic hexagonal grid. Designed for fast performance on mobile browsers, tablets, and desktop computers with **60 FPS procedural rendering**.

---

## ✨ Why Choose This Bubble Shooter Source Code?

Unlike traditional HTML5 games reliant on heavy engines like Phaser or PixiJS, this game utilizes pure native browser APIs for ultra-fast load times and small footprint.

| Feature | Technical Advantage |
|---|---|
| 🚀 **Zero Dependencies** | Pure Vanilla JS — No jQuery, React, Phaser, or third-party SDKs. |
| 🎨 **Procedural Graphics** | Canvas 2D vector rendering for all bubbles, effects, and particle physics. |
| 🔊 **Synthesized Web Audio** | Real-time procedural sound effects & background music via Web Audio API. |
| 📱 **Mobile-First & PWA Ready** | Optimized touch events, safe-area support, and offline playback via LocalStorage. |
| ⚡ **High Performance** | Object pooling, sprite caching, and DPR capping ensure locked 60 FPS. |
| 🔓 **Open Source MIT** | Free for commercial, personal, and educational modification. |

## 🎮 Gameplay Features & Mechanics

- **Classic Hexagonal Grid Engine:** 11-column dynamic grid with offset rows for classic bubble physics.
- **Precision Aim & Trajectory Assist:** Drag-to-aim controls with real-time trajectory bounce visualization.
- **Flood-Fill Matching Algorithm:** Instant recursive cluster detection for 3+ color pops.
- **Floating Cluster Fall Physics:** Detached floating bubbles fall and explode for bonus score combos.
- **Power-ups & Boosters:** Integrated bomb boosters, danger line detection, and adaptive difficulty.
- **20 Handcrafted Levels:** Multi-color progression, procedural backgrounds, and star-rating calculations.
- **Cross-Platform Input System:** Full support for Touch, Mouse, and Keyboard controls.
